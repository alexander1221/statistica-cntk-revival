# CNTK 2.7 revival for TIBCO Statistica 14

Практический разбор восстановления штатного примера MNIST в TIBCO Statistica 14.0.0.15 на Windows x64. Для тех, кто продолжает работать с этой системой и хочет сохранить рабочий сценарий.

**Проверено:** Python-подготовка MNIST → C# Model Building → CNTK CPU-only → Model → Deployment → таблица предсказаний. В переданном тестовом CSV 10 000 строк, 91 ошибка (99,09% точности). Predicted совпадает с argmax вероятностей во всех строках, максимальная погрешность суммы вероятностей 1,19×10⁻⁹. Это результат одного эксперимента; происхождение выборок отдельно не аудировалось.

## Статус воспроизводимости

Скрипты в recipes сохранены из успешного сеанса, требуют настройки путей и подготовленных зависимостей. Это не автономный установщик и не проверенная сборка на чистой Windows. Они предполагают CNTK в C:\CNTK\git-src, Boost в C:\CNTK\deps и Visual Studio Build Tools в стандартном каталоге версии 18. Перед запуском прочитайте рецепт.

В репозитории нет установщиков Statistica, готовых DLL/EXE CNTK, исходных данных MNIST и полной частной переписки. В examples добавлены сохранённые пользователем документы Statistica; они могут содержать модель и отчёты. Для работы нужна собственная установленная Statistica. Сторонние исходники и зависимости доступны у соответствующих проектов и имеют свои лицензии.

## Источники

- CNTK v2.7: https://github.com/microsoft/CNTK/tree/v2.7
- MNIST mirror: https://github.com/fgnt/mnist/tree/master
- Protobuf v3.1.0: https://github.com/protocolbuffers/protobuf/tree/v3.1.0
- MKLML: Windows-пакет mklml_win_2018.0.3.20180406.zip, ссылка найдена в prepare_mkl.bat MKL-DNN v0.14. Проверяйте текущую доступность и лицензию; исторические серверы CNTK частично недоступны.

Проект не связан с TIBCO, Microsoft или Intel. Документированы как удачные шаги, так и ошибки помощника. Помощь и уточнения приветствуются; при сообщении об ошибке убирайте личные пути и прикладывайте команду, версию toolchain и точный лог.
