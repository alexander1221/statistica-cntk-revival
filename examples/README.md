# Рабочие документы Statistica

- **Example_MNIST Digit Recognition.sdm** — сохранённый пользователем пример MNIST.
- **Reporting Documents.stw** — отчёты выполненных запусков.

Документы предоставлены в исходном бинарном формате, без редактирования; проверены сигнатуры OLE Compound File. Повторное открытие этой копии на чистой машине не проверено. Для открытия нужна собственная установленная Statistica; готовый runtime CNTK сюда не включён.

## Запуск

1. Подготовить CNTK по [инструкции](../docs/build-and-install.ru.md).
2. Открыть SDM в Statistica (исходная версия — 14.0.0.15).
3. Проверить код Python/C# и параметры узлов. Для CPU использовать deviceId=-1 в обучении и Deployment.
4. Заново выполнить train/test Data Download: временные пути предыдущей машины могут быть недоступны. Указать собственный постоянный Root directory.
5. Выполнить Model Building, затем Deployment; проверить таблицу предсказаний и отчёт.

В STW сохранены исторические локальные пути, включая имя пользователя и временные GUID. Это отчёт исходного запуска, его пути не предназначены для копирования на другой компьютер. Текстовые рецепты и исправления в docs описывают успешный сеанс; версия кода внутри сохранённого SDM отдельно не подтверждена сравнением.

Общий текст MIT не меняет права на встроенные сторонние образцы или материалы Statistica. Эти файлы не являются установщиком приложения.
