# Исправления C# Deployment

В установленной Statistica 14.0.0.15 метод имеет параметры:

```csharp
ImportSpaceDelimitedSpreadsheet(DataMinerNode node, string path,
                               string formatString, out string errorMessage)
```

В обоих вызовах старого примера добавить пустую строку перед out errormsg. Это значение проверено успешным импортом в описанном сеансе.

В predictionSpreadsheet для каждой строки начинать максимум с double.NegativeInfinity и заново определять predicted; проверять десять выходов на пропуски, NaN и Infinity. Вероятности считать как exp(value - maximum) / sum(exp(value - maximum)). Если вычислять максимум от 0, отрицательные logits могут дать неверный класс; если не вычитать максимум, exp может переполниться.

Пустой catch после формирования таблицы заменить:

```csharp
catch (Exception ex)
{
    throw new Exception("Ошибка формирования таблицы предсказаний", ex);
}
```

Проверять отдельно COMPLETED в отчёте CNTK и создание таблицы приложения. В нашем исправленном CSV число ошибок совпало с CNTK: 91 из 10 000. Это не означает, что та же точность гарантируется любой новой тренировкой.

Внешний тип Model хранит сериализованную модель, а Deployment выполняет оценку. Нажатие на Model само по себе не запускает предсказания. Не переименовывать исторические идентификаторы вроде CNTKMINST без проверки потребителя.
